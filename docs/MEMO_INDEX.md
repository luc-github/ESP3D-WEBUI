# Documentation index

Project documentation lives in **docs/** (English). Below is the list of main documents.

| Document | Description |
|----------|-------------|
| **languagepack.md** | Language packs: templates (`npm run template`), build all (`npm run buildlangpack:all`), fill missing keys, report untranslated (`npm run report-untranslated`), compare (`npm run check`). |
| **languages.md** | Table of language codes and names (generated by `npm run list-languages`). |
| **preferences.md** | Structure of `preferences.json`: user (flash) vs application (in code), settings format, panels order, field types. |
| **variablesList.md** | Variables from firmware output and UI (probe, position, laser) used in macros/templates. |
| **realtimecmd.md** | Real-time commands (grbl/grblHAL): soft reset, feed/rapid/spindle overrides, coolant toggles. |
| **TargetFW.md** | Firmware names and IDs (grbl, marlin, repetier, smoothieware, grblhal, etc.) for target detection. |
| **FEATURES.md** | Feature list by target (global, 3D Printer, CNC, Sand Table). Source: **ESP3D-WebUI-features.xhtml** (converted from .xls, readable). |
| **FEATURES_AND_BUNDLE.md** | Bundle size tracker and main features summary (no protocol detail). |
| **DATA_STRUCTURE.md** | General structure of main objects and context tree. Source: **datastructure.txt** (converted from data structure.odt, readable). |
| **Notes.txt** | Development notes (e.g. Linux/Windows fixes, sass). |
| **EXTENSIONS_MANIFEST.md** | Extension manifest and scan. |
| **FEATHER_ICONS_USED_UNUSED.md** | Icon usage in code. |

For **ESP3D protocol** (commands, response formats, handlers, WebSocket), the reference is **esp3d.io** and the firmware documentation; command behaviour varies by target firmware.
